## 1.テーマ

画像分類、画像検出、(XAI)

## 2.使用する機械学習モデル

ResNet101、Faster R-CNN、Grad-CAM

## 3.研究の動機

医療分野でもAIのモデルが活用されている。希少な症例については、専門医の読影に劣っているものの、一般的な症例については、同等以上の性能を発揮している。しかし、依然として、深層学習の説明可能性については、議論されており、医療現場への導入は限定的である。

そこで、XAIを活用し、AIの判断根拠を可視化し、医師と同じ根拠を持って判断しているか検証、評価することで、AIの判断の信頼性について検証を行う。

また、医師とは全く違う根拠に基づいて、判断される場合、新たな視点での画像検出が可能になるかどうか併せて検証する。

## 4.研究の方法

### ⓪ルールベースの検出

深層学習モデルでの検出の有用性を確かめるために、ルールベースのプログラムを作り、分類、検出する。

### ①画像識別

ResNet101(以下modelA)を使用し、画像識別モデルを学習する。

正解率、適合率、再現率、F値、ROCを使って評価し、精度が担保されるまで、再学習、継続学習を行う。

必要に応じて、損失関数の見直しや、オプティマイザ、スケジューラなどの最適化アルゴリズムを使用して改善を行う。

### ②画像検出

Faster R-CNN(以下modelB)を使用し、ＢＢＯＸの検出を行うモデルを学習する。

正解率、適合率、再現率、Ｆ値、ROCを使って評価し、制度が担保されるまで、再学習、継続学習を行う。

必要に応じて、損失関数の見直しや、オプティマイザ、スケジューラなどの最適化アルゴリズムを使用して改善を行う。

### ③最終検証

①,②で作成したモデルを使ってテストを行い、Grad-CAMを使用して判断根拠を視覚化する。この判断根拠が医師によるアノテーションと整合するかどうか検証する。

また、医師のアノテーションの結果と異なる判断根拠があった場合、ほかの画像と比較し、明確な根拠として確からしいかの検証も行う。

## 5.モデルの説明

| 項目 | modelA:ResNet-101 | modelB:Faster R-CNN |
|---|---|---|
| フェーズと役割 | 画像分類 | 画像検証(BOXの検出) |
| モデルの種類 | CNN | CNN |
| 実装 | torchvision resnet101 | torchvision FasterRCNN+resnet_fpn_backbone("resnet101") |
| 基本構造(過去のプログラムを再利用) | Residual Network | ResNet-101(特徴量抽出)+FPN+RPN+RolHead |
| 層の構成 | 畳み込み層->残差ブロック(3/4/23/3)->プーリング層(全体平均) | ResNet101(全結合層をのぞく)->FPN->RPN->RolAlign->全結合層(12,544->1024->->1024->1024)->予測層 |
| スキップ結合 | あり | あり |
| 追加変更 | fc(2048->1000)をLinear(2048->3)に変更 | 予測層の線形層1024->2から2024->8にする |
| パラメータ数 | 4250160+6147 | 60239065 |
| 入力 | 512×512<br>グレースケールを3chにする | 同じ |
| 前処理 | 1024×1024を½に縮小 | 同じ |
| ラベル | 最終ラベルのみ | 同じ |
| 出力 | 3クラスの確率(softmax) | BOXの座標と確率 |
| 損失関数 | 交差エントロピー | RPN:二値交差エントロピー+SmoothL1<br>RolHead:交差円トロぴー+SmoothL1 |
| 事前学習の重み | ImageNet(IMAGENET1K_V2 | modelAと同じ。<br>FPNとRPNは新規学習・ |
| 学習する範囲 | 全層 | 畳み込み層と層1は固定 |
| 最適化アルゴリズム | SGD（momentum 0.9、weight decay 1e-4。 | SGD（momentum 0.9、weight decay 5e-4。 |
| 学習率 | 0.001~0.01の中から検証用データで決める | 画像1枚あたり0.001 |
| バッチサイズ | 16~32(実際に学習にかかる時間を見て決める) | 4~8 |
| 学習の終了 | 検証用データの指標が一定のepoch数改善しなければ終了する | 同じ |
| 評価指標 | 正解率、クラスごとの適合率・再現率・F値、マクロ平均 F値、クラスごとの ROC-AUC、混同行列 | BOX 単位：IoU 0.5 以上を正解として適合率・再現率・F値・mAP。画像単位：最大の確信度で正解率・F値・ROC |
| 目標の判定に使用する値 | 検証用データのマクロ平均 ROC-AUC | 検証用データの mAP（IoU 0.5） |
| 目標値 | 未定 | 未定 |
| 参考文献 | He et al. (2016) | Ren et al. (2015)、FPN は Lin et al. (2017) |
