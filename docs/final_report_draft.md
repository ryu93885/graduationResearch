# 胸部X線画像における医師アノテーション領域外の特徴を用いた肺炎検出の検討
## ―領域注目・画像全体・領域除外モデルの比較と XAI による判断根拠の分析―

## 要旨

本研究は、胸部X線画像の分類において、医師が肺炎を疑う陰影として囲んだ領域（以下、アノテーション領域）の内側の情報と外側の情報がそれぞれどの程度寄与するかを明らかにすることを目的とする。データには RSNA Pneumonia Detection Challenge 2018 の公式配布データ（30,000 枚）を用いる。アノテーション領域を中心に入力するモデル（Model A）、画像全体を入力するモデル（Model B）、アノテーション領域を隠した画像を入力するモデル（Model C）を同一の条件で学習し、分類性能と Grad-CAM による判断根拠を比較する。

実験に先立ち、公式配布データを取得して構造と特性を検証した。その結果、陽性画像の 77.3% がポータブル撮影（AP）であり、撮影方向だけで ROC-AUC 0.708 の識別が可能であることを確認した。また、データセットの分割に広く使われてきた Kaggle の分割は患者単位ではなく、2,009 人の患者が学習側と評価側の両方に現れることを確認した。最終ラベルの陽性は実質的に読影医が「中・高確率」と判定した陰影であり、「低確率」の陰影がある画像は陰性側に分類されていることも明らかになった。これらの知見に基づき、患者単位の5分割交差検証、事前に定義した評価用の層（読影医の判断が分かれた画像など）、陰性画像への BBox 移植、メタデータのみのモデルとの比較を評価設計に組み込んだ。

モデルの学習と XAI による評価の結果は【未実施】である。

## 第1章 序論

### 1.1 研究背景

深層学習による医用画像の分類モデルは高い精度を示す一方で、その予測がどの画像特徴に基づくかは精度の数値からは分からない。胸部X線画像の分類モデルが、病変そのものではなく撮影条件・施設・画像に写り込んだ文字などの付随情報を手がかりにすること（ショートカット学習）は、すでに複数の研究で報告されている [1][2][3]。したがって、分類性能と判断根拠は併せて検証する必要がある。

本研究では、医師が肺炎を疑う陰影として囲んだ矩形領域を「医師アノテーション領域」と呼ぶ。RSNA のデータセットにおける Bounding Box（BBox）は陰影を囲む矩形であり、病変の輪郭そのものではない。そのため本研究は、AI と医師の診断過程全体を比較するものではない。モデルに与える入力を、アノテーション領域の内側・画像全体・アノテーション領域を除いた画像の3通りに変え、その違いを比較するものである。

### 1.2 研究目的

本研究の目的は次の2点である。

1. アノテーション領域の内側と外側の情報が、それぞれ胸部X線画像の分類にどの程度寄与するかを定量的に示す。
2. XAI（Grad-CAM など）が示す判断根拠が、アノテーション領域とどう対応し、モデルの実際の予測をどの程度忠実に反映しているかを評価する。

### 1.3 研究課題

- **RQ1**：アノテーション領域を中心に学習したモデルと画像全体で学習したモデルでは、分類性能と判断根拠がどう異なるか。
- **RQ2**：アノテーション領域を除いた画像から、肺炎を疑う所見の有無をどの程度分類できるか。
- **RQ3**：XAI が示す重要領域はアノテーション領域とどう関係し、その説明はどの程度予測を忠実に反映しているか。

### 1.4 仮説

- **H1**：アノテーション領域の外側にも、分類に使える情報が存在する。
  - H1 は単純に検証すると、撮影条件などの付随情報によってほぼ確実に成立してしまう。そこで本研究では H1 を次の3段階に分け、それぞれの判定基準を実験前に定める（R-05）。
  - **H1a**：アノテーション領域を隠しても、分類に使える信号が残る。
  - **H1b**：その信号は、撮影条件などのメタデータだけで説明できる水準を上回る。
  - **H1c**：その信号は肺野の中にある。
- **H2**：画像全体のモデルが強く反応する領域のうち、アノテーション領域の外側にあるものを XAI で示せる。ただし、XAI の可視化だけでは新しい医学的所見の発見や臨床的有用性を主張しない。

## 第2章 関連研究【要確認：書誌情報は原典で確認する】

### 2.1 胸部X線データセット

NIH ChestX-ray8/14 は、NIH Clinical Center の正面胸部X線画像 112,120 枚（30,805 人）に、読影レポートから自然言語処理で抽出した 14 種類の所見ラベルを付けたデータセットである [4]。ラベルは自動抽出であるため誤りを含む。RSNA Pneumonia Detection Challenge 2018 のデータセットは、この中から 30,000 枚を選び、18 人の放射線科医が肺炎を疑う陰影の有無と位置を手作業で付け直したものである [5]。

### 2.2 ショートカット学習

Geirhos らは、標準的な評価では高い性能を示すが、意図した特徴とは異なる手がかりに依存する決定規則を「ショートカット学習」として整理した [1]。胸部X線では、Zech らが肺炎検出モデルの性能が施設をまたぐと低下し、モデルが撮影施設そのものを識別できることを示した [2]。DeGrave らは、COVID-19 の検出モデルが病変ではなく画像の文字マーカーや辺縁などに依存していたことを示した [3]。

### 2.3 判断根拠の可視化と評価

Grad-CAM は、CNN の特徴マップと勾配から、予測に寄与した画像領域をヒートマップとして示す手法である [6]。可視化手法には、モデルや学習データに依存しない出力を返すものがあり、健全性の確認が必要であることが指摘されている [7]。説明の忠実性の評価には、重要とされた領域を順に削除・挿入して予測の変化を測る Deletion/Insertion [8] や、重要とされた特徴を除いて再学習する ROAR [9] がある。胸部X線では、可視化手法の位置特定の性能が放射線科医の水準に届かないことが報告されている [10]。

## 第3章 データセットと事前検証

### 3.1 データの取得

RSNA の公式配布ページ [11] から、次のファイルを取得した。各ファイルのサイズと SHA-256 を記録し、画像 ZIP は全 30,000 ファイルの CRC を検査して破損がないことを確認した。

| ファイル | サイズ | 内容 | 本研究での用途 |
|---|---|---|---|
| `pneumonia-challenge-annotations-adjudicated-kaggle_2018.json` | 52.0 MB | 30,000 枚分の全読影医のラベル（確率つき）、調整の記録、最終ラベル | 主解析・読影医ごとの分析 |
| `pneumonia-challenge-dataset-adjudicated-kaggle_2018.zip` | 3.98 GB | 30,000 枚の DICOM 画像 | すべての解析 |
| `pneumonia-challenge-dataset-mappings_2018.json` | 17.6 MB | RSNA 画像と NIH 元画像の対応、NIH ラベル、選定グループ | 患者単位の分割、選定の偏りの分析 |
| `pneumonia-challenge-annotations-original_2018.json` | 19.6 MB | Kaggle stage 1 train（25,684 枚）の2値ラベル | 読み込みの検算 |

配布ページの名称から当初は「initial annotations」に読影医ごとの情報があると想定したが、実際には `*-adjudicated-kaggle_2018.json` にすべての情報が含まれていた（R-15）。`*-original_2018.json` の2値ラベルは、本研究で読み込んだ最終ラベルと 25,684 枚すべてで一致し、読み込み処理の正しさを裏付けた。

データの利用にあたっては RSNA の利用規約 [12] に従い、個人の特定や接触を試みない。共有・再配布の際は NIH と RSNA の帰属表示を行う。データの利用は指導教員の確認を得ている。

### 3.2 画像の性質

30,000 枚はすべて 1024×1024 画素、8 ビット、MONOCHROME2 であり、画素データは JPEG Baseline（非可逆）で圧縮されている。撮影方向は PA が 16,248 枚、AP が 13,752 枚である。DICOM には年齢・性別・撮影方向に加えて PixelSpacing が記録されており、その値は画像によって異なる（主に 0.139、0.143、0.168、0.171、0.194 mm）。年齢には 100 を超える値が 6 件あり、最大は 412 であった。これは入力の誤りと判断し、欠損として扱う（R-22）。

### 3.3 ラベルとアノテーションの構造

アノテーションは MD.ai の形式で記録されており、読影グループごとに次の役割を持つ。

| グループ | 役割 |
|---|---|
| Team 1 | 1人読影。6 人の読影医が約 5,000 枚ずつ担当した |
| Team 2 / Team 2a | 3人読影の追加の読影医 |
| Adjudication | 意見の不一致などの調整 |
| Calculated | 最終ラベル（Lung Opacity と BBox / No Lung Opacity・Not Normal / Normal） |

最終ラベルの内訳は、Lung Opacity 7,106 枚（BBox 11,390 個）、No Lung Opacity / Not Normal 12,788 枚、Normal 9,790 枚であり、316 枚には最終ラベルがない。最終ラベルのない画像は解析から除外し、解析対象は 29,684 枚とする（R-23）。陽性率は 23.9% である。陽性画像 1 枚あたりの BBox は 1 個が 3,030 枚、2 個が 3,892 枚、3 個が 160 枚、4 個が 24 枚である。

3人読影（Team 2 と Team 2a の両方が読影）の画像は 4,526 枚であり、RSNA の公表値 4,527 枚とほぼ一致した。3人読影では読影医の BBox の交差が最終 BBox とされているため [5]、最終 BBox の面積の中央値は3人読影で画像の 3.8%、1人読影で 6.5% と、3人読影のほうが小さい。

### 3.4 データの特性の分析

#### 3.4.1 撮影方向による偏り

陽性率は AP で 40.5%、PA で 10.0% であり、陽性画像の 77.3% が AP であった（陰性画像では 35.7%）。撮影方向だけを予測値としたときの ROC-AUC は 0.708 である。AP 撮影はベッド上の重症患者に多く用いられるため、撮影方向は肺炎の有無と強く結びついた付随情報であり、モデルのショートカットとなりうる（R-06）。

PixelSpacing も陽性率と関係していた。1,000 枚以上ある組み合わせで比べると、PA の中でも PixelSpacing によって陽性率は 8.2%〜14.3% と異なった。PixelSpacing は撮影機器の違いを反映していると考えられ、撮影方向とは別のショートカットの候補である（R-19）。また、一部の画像には文字マーカーの写り込みを目視で確認した。

#### 3.4.2 画像の選定による偏り

30,000 枚は、NIH のラベルで肺炎関連（浸潤影・コンソリデーション・肺炎など）が 15,000 枚、No Finding が 7,500 枚、その他の所見が 7,500 枚となるように選ばれている。再読影後の陽性率は、それぞれ 34.5%、9.0%、17.9% であった。本データセットは肺炎疑い例を意図的に多く含むため、陽性率や Precision を臨床の集団にそのまま一般化することはできない（R-18）。

#### 3.4.3 読影医の判定と最終ラベルの関係

1人読影の画像において、読影医が低確率の BBox しか描かなかった画像は、ほぼすべて（1,689 枚中 1,620 枚）が最終ラベルで No Lung Opacity / Not Normal とされていた。したがって、最終ラベルの Lung Opacity は実質的に「中・高確率」の陰影であり、低確率の陰影がある画像は陰性側に含まれる。この対応は公式資料には記載がなく、データから推定したものである（R-17）。

3人読影で3人の判定がそろう 4,497 枚について、陽性かどうかの一致度は Fleiss の κ [15] = 0.497 であり、3人の判定が全員一致したのは 64.5% であった。最終ラベルが陰性であるにもかかわらず陽性と読んだ読影医がいる画像は 862 枚、最終ラベルが陽性であるにもかかわらず陰性と読んだ読影医がいる画像は 774 枚あった。

3人読影の陽性画像 1,639 枚では、全読影医の BBox の和集合の面積は最終 BBox の中央値 2.47 倍（四分位範囲 1.74〜3.62 倍）であり、和集合の 59%（中央値）が最終 BBox の外側にあった。すなわち、最終 BBox の外側にも、ほかの読影医が陰影と判断した領域が広く残っている。

#### 3.4.4 患者とデータ分割

30,000 枚は NIH の患者 12,274 人に由来し、1 人あたり最大 75 枚の画像がある。画像が 1 枚だけの患者は 7,464 人である。Kaggle のコンペで用いられた分割は患者単位ではなく、2,009 人の患者が stage 1 train とそれ以外の両方に画像を持つ。また、3人読影の 4,526 枚のうち 3,273 枚は、同じ患者の1人読影の画像がある。したがって、既存の分割や「3人読影の画像を評価用にする」分け方をそのまま用いると、同一患者の画像が学習と評価の両方に入り、性能を過大に評価するおそれがある（R-03）。

## 第4章 方法

### 4.1 評価用の層

読影医の判断の確かさによって画像を次の4つの層に分け、結果を層ごとにも報告する（R-25）。層は実験前に定義し、結果を見て変更しない。いずれの層の画像も学習と主評価から除外しない。

| 層 | 定義 | 枚数 |
|---|---|---|
| multi_unanimous | 3人読影で、最終ラベルが読影医の全員一致の判定と同じ画像 | 2,876 |
| multi_difficult | 3人読影で、陽性かどうかの意見が割れた画像、または全員一致の判定が最終ラベルで覆された画像 | 1,636 |
| single_low_prob | 3人読影以外で、読影医が低確率の BBox しか描かなかった画像 | 1,691 |
| single_other | 上記以外 | 23,481 |

multi_difficult は両方向の画像を含む（最終ラベルが陰性で陽性と読んだ読影医がいる 862 枚、最終ラベルが陽性で陰性と読んだ読影医がいる 774 枚）。両方向を含めることで、この層の中でも感度・特異度・AUC を計算でき、multi_unanimous と比較できる。single_low_prob は読影医自身の確信の低さを表すものであり、読影医間の不一致とは性質が異なるため、別の層とする。

### 4.2 データ分割

患者単位の5分割交差検証を用いる（R-26）。同一患者の画像はすべて同じ組に割り当てる。画像の多い患者から順に、最終ラベル × 評価用の層 × 撮影方向の内訳と画像数が最もそろう組に割り当てた。分割の偏りの許容範囲は事前に定め（画像数・患者数は平均の ±5%、各層の枚数は ±10%、陽性率と AP の割合は ±1 ポイント）、すべての項目がこれを満たした。

| 組 | 患者 | 画像 | 陽性率 | AP の割合 | multi_difficult |
|---|---|---|---|---|---|
| 0 | 2,447 | 5,937 | 0.239 | 0.457 | 327 |
| 1 | 2,447 | 5,938 | 0.239 | 0.457 | 328 |
| 2 | 2,447 | 5,937 | 0.239 | 0.456 | 328 |
| 3 | 2,446 | 5,936 | 0.239 | 0.457 | 327 |
| 4 | 2,446 | 5,936 | 0.239 | 0.456 | 326 |

各回 k（k = 0〜4）では、組 k を評価用、組 k+1 を検証用、残りの3組を学習用とする（R-27）。5 回の評価で全画像が1回ずつ評価用となるため、multi_difficult の 1,636 枚すべてを評価に用いることができる。分割は乱数の種（42）から再現でき、指紋 `5f2c2423bfaa75b3` によって環境の違いによらず同一であることを確認できる。

### 4.3 比較するモデル

すべてのモデルで同じネットワーク構造・学習条件・分割を用い、入力領域だけを変える（R-08）。入力は画像全体の大きさのまま与え、領域の切り出しによる拡大率の違いを生じさせない。

| モデル | 入力 | 目的 |
|---|---|---|
| Model B | 画像全体 | 基準 |
| Model A | BBox の内側だけを残し、外側を塗りつぶした画像 | 領域内の情報量（RQ1） |
| Model C | BBox の内側を塗りつぶした画像 | 領域外の情報量（RQ2、H1） |
| Model C-rand | BBox と同じ面積のランダムな領域を塗りつぶした画像 | 塗りつぶし操作そのものの影響（対照） |
| メタデータモデル | 年齢・性別・撮影方向・PixelSpacing のみ（ロジスティック回帰） | 画像を見ずに達成できる性能の基準（H1b） |

**陰性画像への BBox 移植**（R-01）：陰性画像には BBox がないため、そのままでは「塗りつぶしの有無」が正解を示してしまう。そこで陰性画像には、同じ組・同じ撮影方向の陽性画像から無作為に選んだ BBox 一式（数・大きさ・位置）を移植し、陽性画像と同じ手順で塗りつぶす。【案】読影医が BBox を描いた陰性画像（R-25）も、主解析では同じ移植の手順で扱う。

**塗りつぶしの方法**（R-09）：主解析では画像の平均値で塗りつぶす。比較として周囲からの補間（inpainting）を用いる。ぼかしは陰影（低周波の濃度上昇）を残すため用いない。BBox が陰影を完全に囲んでいないことによる情報の漏れを調べるため、BBox を 0・10・25・50% 拡張して塗りつぶし、AUC の変化を示す。さらに、最終 BBox ではなく全読影医の BBox の和集合を塗りつぶす条件を設ける。和集合は最終 BBox より中央値で 2.47 倍広く（3.4.3 節）、この条件でも分類できれば H1 の根拠はより強くなる。

### 4.4 学習の条件【未確定】

- 画像は 1024 画素から縮小して保存し、学習に用いる（R-24）。解像度は 512 画素を基本とする。【未確定：研究室の GPU の性能（Q-11）を確認して決める】
- ネットワークは ImageNet で事前学習した CNN（ResNet-50 または DenseNet-121）とする。【未確定】NIH ChestX-ray14 で学習した重みは、評価用の画像を学習時に見ている可能性があるため用いない（R-04）。
- 検証用の組の AUC で学習の打ち切りを決め、検証用の組で判定のしきい値を決める。評価用の組はしきい値の調整に用いない。【案】しきい値は Youden 指数で決める。
- 乱数の種を変えた繰り返しの回数は【未確定】。

### 4.5 分類性能の評価

- 指標は Accuracy、Precision、Recall（感度）、Specificity、F1、ROC-AUC、PR-AUC とする。陽性率が 23.9% であるため、Accuracy は単独では用いない。
- 5 回の評価用の組の予測を統合して全画像の予測を得る。指標は全体と評価用の層ごと、撮影方向（AP / PA）ごとに算出する。
- 信頼区間は患者単位のブートストラップで求める。同じ画像に対する2つのモデルの AUC の差は、DeLong 検定 [13] または患者単位のブートストラップで評価する（R-12）。
- Model B のテスト時だけ BBox を塗りつぶし、予測スコアの低下を測る（R-10）。これは再学習した Model C とは異なり、「画像全体のモデルがアノテーション領域にどれだけ依存しているか」を示す。

### 4.6 判断根拠（XAI）の評価

- 主に Model B に Grad-CAM [6] を適用し、Model A・C にも適用して入力領域による違いを比較する。結論が手法に依存しないことを確かめるため、Grad-CAM 以外の手法を 1 つ加える（R-11）。【未確定：手法の選択】
- **領域との対応**：ヒートマップの値が最終 BBox の内側に占める割合（Energy-based pointing game [14]）を、BBox の面積で補正して求める。
- **領域外の反応の分類**：最終 BBox の外側の反応を、(i) ほかの読影医の BBox の内側、(ii) どの読影医の BBox にも入らない肺野内、(iii) 肺野外、に分ける。本当に「医師が陰影と見なかった領域」と言えるのは (ii) である。(iii) への強い反応はショートカットの疑いとして扱う。肺野の範囲は、NIH・RSNA の画像で学習していない肺野セグメンテーションのモデルで求める。【未確定：モデルの選択】
- **判断の難しい画像での分析**：multi_difficult のうち最終ラベルが陰性の 862 枚について、モデルが陽性と予測した画像のヒートマップが、陽性と読んだ読影医の BBox と重なるかを調べる。
- **忠実性**：Deletion / Insertion [8] によって、ヒートマップの上位の領域を削除・挿入したときの予測の変化を測る。また、画像ごとの「BBox 内のヒートマップの割合」と「テスト時に BBox を隠したときのスコアの低下」（4.5 節）の相関を求める。
- **健全性の確認**：モデルの重みをランダムにしたときにヒートマップが変化することを確かめる [7]。
- **安定性**：乱数の種や交差検証の回によるヒートマップの変化を調べる。

### 4.7 感度分析

最終ラベルの陽性は中・高確率の陰影、陰性には低確率の陰影や意見の割れた画像が含まれる（3.4.3 節）。主解析の結論がラベルの定義に依存しないことを確かめるため、次の2つの条件でも評価する（R-17）。

1. 高確率の陰影のある画像だけを陽性とする。
2. どの読影医も BBox を描いていない画像だけを陰性とする。

### 4.8 仮説の判定基準【案】

結果を見る前に次の基準を確定する（R-05）。

| 仮説 | 判定基準【案】 |
|---|---|
| H1a | Model C の AUC の 95% 信頼区間の下限が 0.5 を上回る。Model C-rand の AUC が Model B と同程度である（塗りつぶし操作だけで性能が下がらない） |
| H1b | Model C の AUC がメタデータモデルの AUC を上回り（差の 95% 信頼区間が 0 を含まない）、AP・PA それぞれの層の中でも Model C の AUC の 95% 信頼区間の下限が 0.5 を上回る |
| H1c | Model C の Grad-CAM の値の過半が肺野内にあり、BBox の拡張や和集合での塗りつぶしでも H1a が成り立つ |
| H2 | Model B の BBox 外の反応のうち、(ii) どの読影医の BBox にも入らない肺野内の領域への反応が、忠実性の評価（Deletion）で予測に寄与していることを示す |

## 第6章 考察

### 6.1 事前検証から得られた知見

本データセットでは、撮影方向と PixelSpacing が陽性と強く結びついている。したがって、画像全体のモデルの高い性能や、アノテーション領域を除いたモデルの分類能力は、それだけでは肺炎の画像所見を捉えた証拠にならない。本研究がメタデータモデルとの比較と撮影方向ごとの評価を判定基準に組み込んだのは、この理由による。

最終 BBox は3人読影では読影医の BBox の交差であり、和集合の 59% は最終 BBox の外側にある。最終 BBox だけを塗りつぶした場合、塗りつぶしの外側にほかの読影医が陰影と判断した領域が残る。このため、最終 BBox の外側への反応を直ちに「医師が見ていない領域への反応」と解釈することはできず、読影医ごとの BBox を用いた領域外の反応の分類（4.6 節）が必要である。

また、最終ラベルの陰性には、低確率の陰影がある画像や読影医の意見が割れた画像が含まれる。モデルがこれらの画像を陽性と予測することは、必ずしも誤りではなく、一部の読影医の判断と一致している可能性がある。

### 6.2 モデルの結果に関する考察【未実施】

### 6.3 限界

- BBox は陰影を囲む矩形であり、病変の輪郭ではない。本研究の「領域内」「領域外」は、医師アノテーション領域を基準とした区別である。
- ラベルは肺炎を疑う画像所見の分類であり、臨床的な診断ではない。読影医は臨床情報なしに画像だけを見て判断している。
- データは単一施設（NIH Clinical Center）の画像であり、ほかの施設での一般化は検証できない。一方で、施設の違いによる交絡は生じない。
- 画像は 8 ビットに変換され、JPEG で非可逆圧縮されている。
- データセットは肺炎疑い例を多く含むように選ばれており、陽性率は臨床の集団とは異なる。
- XAI のヒートマップはモデルの内部の判断過程を完全には説明しない。本研究では可視化だけから因果的な主張は行わない。
