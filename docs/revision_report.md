## 2026-11-13 研究の組み立て直しとモデルの初期構造の相談（Q-16〜Q-19）

### 相談内容

- 研究を3つのフェーズで行う。データセットはこれまでと同じ（RSNA Pneumonia Detection Challenge 2018）。
  1. 画像分類：ResNet-101
  2. 画像検出（BOX の検出）：MedSAM
  3. Grad-CAM による説明可能性の検証
- フェーズ1・2のモデルの初期構造（線形層・回帰層・スキップ層などの追加）をどう定義するか。最適化アルゴリズムは公式論文を参考にする。

### 回答の要点

- **ResNet-101**：本体は変えず、最後の全結合層 `fc(2048→1000)` を新しい線形層に置き換えるだけでよい。スキップ接続は全 33 ブロックにすでにある。中間層を足さなければ、Grad-CAM は CAM（Zhou et al., 2016）と定数倍を除いて一致し、判断根拠の解釈が単純になる。
- **MedSAM**：画像と BOX のプロンプトを入力すると、その中の領域のマスクを返すモデルであり、単独では BOX を検出しない。RSNA にはマスクの正解もないため、MedSAM の損失（BCE＋Dice）でそのまま学習することもできない。次の4案を示し、案 A を推奨した。

  | 案 | 内容 |
  |---|---|
  | A | MedSAM の Image Encoder を特徴抽出器にして、検出ヘッド（分類＋回帰）を追加する |
  | B | 別の検出器で BOX を出し、MedSAM でマスクにする |
  | C | フェーズ1の Grad-CAM から BOX を作り、MedSAM に入れる（フェーズ3の検証が循環するので勧めない） |
  | D | 正解の BOX をプロンプトにして疑似マスクを作る（検出にはならないが、フェーズ3の参考にはなる） |

- **最適化**：ResNet 論文の学習率 0.1 と学習回数は、ImageNet をゼロから学習するときの設定である。ファインチューニングでは変える必要がある。
- **入力の大きさ**：ResNet-101 の入力は 224 より 512 を勧めた。224 では Grad-CAM が 7×7 マスになり、BOX と比べるには粗い。

### 研究の構成（ユーザーの構成案より）

- **テーマ**：画像分類、画像検出、XAI
- **動機**：医療分野の AI は、一般的な症例では専門医と同等以上の性能を出す。一方で、深層学習の説明可能性が議論されており、医療現場への導入は限られている。そこで XAI で AI の判断根拠を可視化し、医師と同じ根拠で判断しているかを検証・評価して、AI の判断の信頼性を確かめる。あわせて、医師とまったく違う根拠で判断している場合に、新しい視点での画像検出ができるかどうかも検証する。
- **方法**
  1. modelA（ResNet-101）で画像分類のモデルを学習する。正解率・適合率・再現率・F値・ROC で評価し、精度が担保されるまで再学習する。必要に応じて損失関数・オプティマイザ・スケジューラを見直す。
  2. modelB で BOX を検出するモデルを学習する。評価と改善の進め方は 1 と同じ。
  3. 1・2 のモデルでテストを行い、Grad-CAM で判断根拠を可視化する。判断根拠が医師のアノテーションと整合するかを検証する。医師と異なる根拠があった場合は、他の画像と比べて、根拠として確からしいかを検証する。

### 検出モデルの提案：Faster R-CNN（Backbone：ResNet-101-FPN）

1. modelA と同じ ResNet-101 を土台に使える。両方のモデルで Grad-CAM を同じ層（layer4）にかけられるので、判断根拠を同じ条件で比べられる。
2. ResNet の論文（He et al., 2016）自体が、ResNet-101 ＋ Faster R-CNN で物体検出の結果を報告している。
3. PyTorch の torchvision に標準で入っており、検出ヘッドを自作する必要がない。BOX のない画像も、そのまま学習に使える。
4. 1枚に複数の BOX を扱える（陽性画像の過半数、3,892 / 7,106 枚は BOX が2個）。

| モデル | ResNet-101 との相性 | 手軽さ | 備考 |
|---|---|---|---|
| Faster R-CNN（推奨） | ResNet-101 をそのまま土台にできる | torchvision に標準搭載 | 2段階型の代表的なモデル |
| RetinaNet | ResNet-101 を土台にできる | torchvision に標準搭載 | 1段階型。次の候補 |
| YOLO | 独自の土台（ResNet ではない） | 簡単 | modelA と比べにくい。ライセンスが AGPL |
| DETR | ResNet-101 を土台にできる | 学習に数百 epoch かかる | このデータの量では収束しにくい |

- torchvision には、ResNet-101 版の COCO で学習済みの重みがない。土台は modelA と同じ ImageNet の重みから始め、FPN・RPN・検出ヘッドは新しく学習する。精度が足りないときは、COCO で学習済みの ResNet-101 版がある Detectron2 に切り替える選択肢がある。
- torchvision は既定で画像の短辺を 800 に拡大するので、`min_size=512, max_size=512` に固定する。

### 3クラス分類にするときの注意

- アノテーションの BOX と比べられるのは Lung Opacity だけである。「No Lung Opacity / Not Normal」は、フェーズ3で数値による照合ができないため、図で示して説明する。
- クラスの枚数の差は最大でも約 1.8 倍（7,106／12,788／9,790）なので、最初はクラスの重み付けをしない。

### 1024×1024 → 512×512 の縮小の検証（Q-18）

2026-11-12 のデータ確認（30,000 枚すべての DICOM ヘッダと BOX の集計）の記録をもとに確かめた。**結論：512×512 に縮小して問題ない。**

| 確認項目 | 確認した事実 | 判定 |
|---|---|---|
| 画像サイズ | 30,000 枚すべて 1024×1024 | ちょうど 1/2 になる。縦横比が変わらず、余白も不要。BOX の座標は 2 で割るだけでよい |
| 画質 | 8 ビット、配布時点で JPEG（非可逆）圧縮済み | 2×2 画素の平均で縮小すれば、ずれやひずみは出ない |
| 1画素の実寸 | 0.139〜0.194 mm → 0.28〜0.39 mm | BOX の中央値は実寸で約 3〜5 cm。肺炎の陰影を写すには十分 |
| BOX の大きさ | 中央値 約 220×308 px → 約 110×154 px。最小 約 40×38 px → 約 20×19 px | 検出は可能。最小のアンカー（32 px）より小さい BOX はごく一部と見込む |
| Grad-CAM の細かさ | layer4 の出力は 16×16（1マス＝32 px、元の画像では 64 px） | 中央値の BOX は約 3×5 マスで比較できる。最小の BOX は1マスより小さいので、layer3（32×32）も併用する |

- 「No Lung Opacity / Not Normal」には結節など小さい所見も含まれるので、縮小の影響が Lung Opacity より出やすい可能性がある。所見によって必要な解像度が違うという報告がある（Sabottke & Spieler, 2020, Radiology: AI【要確認】）。
- **実装の段階で行う確認**
  1. 縮小画像に BOX（座標 ÷2）を重ね、ずれがないことを各クラス数枚で目で確かめる。
  2. 縮小後に 32 px 未満になる BOX の数と割合を数える。多ければ、アンカーを 16 px から始める。
  3. （任意）1つの分割だけで modelB を 1024 でも学習し、512 との性能の差が小さいことを示す。
  4. 縮小画像は一度だけ作って PNG（可逆圧縮）で保存し、modelA・modelB と、Colab・ローカルの両方で使い回す（R-24 と同じ考え方）。

### フェーズ3で「BOX とどれだけ合うか」を測る指標（案）

- **Pointing game**：Grad-CAM の最大の点が正解 BOX の中に入る割合
- **BOX 内の割合**：Grad-CAM の値の合計のうち、正解 BOX の中にある割合
- **IoU**：Grad-CAM の上位の領域（例：上位 20%）と正解 BOX の重なり

**解釈の注意**
- modelB は BOX を教えて学習するので、根拠が BOX と合うのはある程度当然である。BOX を教えずにラベルだけで学習した modelA の根拠が BOX とどれだけ合うかが、この研究の中心的な結果になる。
- 「医師と異なる根拠」は、新しい所見ではなく近道（ショートカット）の可能性もある。たとえば、撮影方向（AP だけで陽性を ROC-AUC 0.708 で予測できる。R-19）、文字のマーカー、チューブ類である。

| 照合の指標【案】 | Pointing game、BOX 内の割合、Grad-CAM の上位 20% の領域と BOX の IoU | 同じ |
